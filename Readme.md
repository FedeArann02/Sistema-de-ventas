## 🚀 Funcionalidades Principales

- 📦 **Gestión de Artículos:** Control completo sobre el inventario.
- 🧑‍🤝‍🧑 **Gestión de Clientes:** Administra tu base de clientes de manera eficiente.
- 🤝 **Gestión de Proveedores:** Mantenimiento de relaciones comerciales con proveedores.
- 🛡️ **Gestión de Usuarios:** Control de acceso y manejo de los usuarios del sistema.
- 📄 **Gestión de Remitos y Presupuestos:** Procesos de ventas y pre-ventas organizados.
- 📊 **Balances y Reportes:** Visualización clara de la situación financiera de tu negocio.

## 🛠️ Instalación y Configuración

1. Clona el repositorio:  
   `git clone https://github.com/FedeArann02/Sistema-de-ventas`
2. Configura la base de datos en SQL Server ejecutando los scripts SQL ubicados en la carpeta `/Database`.
3. Abre la solución en Visual Studio 2022.
4. Configura la cadena de conexión en `appsettings.json` para apuntar a tu servidor SQL.
5. Ejecuta el proyecto y disfruta del control organizado de tu negocio.
